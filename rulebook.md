# 🎯 Game Rules

## Objective
Be the first player to reach **10 Victory Points**.

## Setup
1. A player is selected randomly to locate one Bohío and one Stone Path.
2. Go through the players in a clockwise fashion until the last one to do the same thing.
3. The last player should place an additional Bohío and Stone Path.
4. Go through the players in a counter clockwise fashion until the first one to do the same thing.
5. Give each player one resource that matches each of the connected areas to their last building.
6. The setup is now ready and the first player can start their turn.

## Turn Structure
1. **Roll Dice** - Determine which hexes produce resources
2. **Collect Resources** - All players collect from matching hexes
3. **Trade & Build** - Construct buildings, buy cards, trade with players
4. **End Turn** - Pass to the next player

## Victory Points
- Each Terrace = 1 VP
- Each Great Terrace = 2 VP
- Longest Path (5+ roads) = 2 VP
- Largest Army (3+ warriors) = 2 VP
- Certain Wisdom Cards = 1 VP each

## The Conquistador
When a 7 is rolled:
1. Players with >7 cards discard half
2. Active player moves the Conquistador
3. Steal 1 resource from an adjacent player
4. The blocked hex produces no resources

## Game Elements

## Resources
| Resource | Source |
|----------|--------|
| Gold | Mountains |
| Stone | Quarries |
| Cotton | Highlands |
| Maize | Valleys |
| Wood | Jungle |

## Buildings
| Building | Cost | Victory Points |
|----------|------|----------------|
| Stone Path | 1 Stone + 1 Wood | 0 |
| Terrace | 1 Stone + 1 Wood + 1 Cotton + 1 Maize | 1 |
| Great Terrace | 3 Gold + 2 Maize | 2 |

## Wisdom Cards
- Manikato Warrior - Move the Conquistador
- Blessing of Aluna - Take 2 resources
- Wisdom of the Mama - Monopoly on a resource
- Pathfinder - Build 2 free roads
- Legacy of the Elders - 1 Victory point
